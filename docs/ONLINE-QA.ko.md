# 온라인 대국 검증 · 2026-09-16

대상은 기존 파문·침식·유산 세 게임입니다. 일반 오목과 앞서 논의한 스왑 규칙은 추가하지 않았습니다.

## 검증 결과

- 타입 검사 통과.
- 규칙·저장·온라인 API 단위 테스트 총 27개 통과. 기존 규칙 검증에는 150판 무작위 대국이 포함됩니다.
- 브라우저 시나리오 총 26개 확인: 첫 실행 24개 통과 후 발견한 재대국 경합을 수정하고, 해당 재대국 및 터치 테스트 2개 재실행 통과.
- 세 게임 모두 서로 다른 Chromium 브라우저 컨텍스트 두 개에서 실제 UI로 끝까지 대국하고 최종 판을 비교했습니다.
- 새로고침 시 참가자 색과 기보 유지, 잘못된/없는 방, 세 번째 참가자 거절, 상대 차례 클릭 차단, 네트워크 단절 후 복구, 기권, 방 나가기, 양쪽 동의 재대국 및 흑백 교대를 확인했습니다.
- 320·390·768px 가로 넘침 없음. 터치 한 번 착수, 실제 포인터 down/up 착수 확인. Pretendard를 포함한 데스크톱·모바일 화면을 확인했습니다.

## 서버 경합과 보안 검증

`tests/online.test.ts`는 실제 운영 SQL과 생성된 마이그레이션을 Node SQLite에서 실행합니다. SQL 문자열을 흉내 낸 데이터베이스 모킹을 사용하지 않습니다.

- 동시 입장 두 요청 중 한 명만 두 번째 자리를 차지합니다.
- 같은 방 생성 요청을 재시도해도 방이 중복 생성되지 않습니다.
- 토큰 미소지자, 다른 참가자, 잘못된 차례, 불법 수, 오래된 판 버전을 거절합니다.
- 중복 착수 요청은 요청 ID로 한 번만 처리합니다.
- 응답에는 참가자 인증 토큰, 토큰 해시, 내부 요청 기록이 포함되지 않습니다.
- 재대국 동의는 같은 회차에서 두 요청을 합칠 수 있게 처리합니다. 오래된 회차의 동의로 다음 대국을 시작할 수 없습니다.
- 만료, 닫힌 방, 본문 크기 제한, 허용 Origin, 시간 구간별 방 생성 제한을 검사했습니다.

## 한계와 운영

로컬 SQLite 검증은 실제 Cloudflare D1의 배포·바인딩 검증을 대체하지 않습니다. 운영 배포 후 별도로 공개 API와 GitHub Pages의 교차 출처 연결을 확인합니다. 물리적으로 서로 다른 통신망이나 실제 iOS Safari 기기는 이번 자동 테스트에 포함하지 않았습니다.

온라인은 웹소켓 대신 약 1.2초 주기로 서버 상태를 읽습니다. 네트워크가 느리면 반영까지 더 걸릴 수 있습니다. 방은 생성 시점부터 24시간 이용할 수 있고, 탭의 입장 정보를 잃으면 기존 자리로 돌아오지 못할 수 있습니다. 만료 데이터 정리는 새 방 생성 시 제한된 개수씩 수행합니다.
